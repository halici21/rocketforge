# Reference data sources

Every expected value used by `tests/physics/` is recorded here with the source
it was confirmed against. The rule from
`docs/engineering/05_verification_and_validation_plan.md` section 7 is that a
value generated by RocketForge itself is **not** a reference: it must be
confirmed against an independent authority before the module that produces it
can be accepted.

---

## NACA Report 1135 (primary source for values)

* **Title**: *Equations, Tables, and Charts for Compressible Flow*
* **Authors**: Ames Research Staff
* **Report**: NACA Report 1135 (1953)
* **Publisher**: National Advisory Committee for Aeronautics
* **Copy used**: the scan hosted by NASA at
  <https://www.nasa.gov/wp-content/uploads/2023/03/equations-tables-charts-compressibleflow-report-1135.pdf>
* **Accessed**: 2026-08-30
* **Status**: US Government work, public domain.

Values were read directly from the printed tables in that scan:

| Table | Report page | Content used |
| --- | --- | --- |
| Table I — SUBSONIC FLOW, γ = 7/5 | 633 | M = 0.50 and M = 1.00 rows; the A/A* column at M = 0.37 and M = 0.38 |
| Table II — SUPERSONIC FLOW, γ = 7/5 | 633 | M = 1.00 row |
| Table II — SUPERSONIC FLOW, γ = 7/5 | 634 | M = 2.00 row |
| Table II — SUPERSONIC FLOW, γ = 7/5 | 635 | M = 3.00 row |

Column headings, as defined in the "NOTATIONS FOR TABLES I AND II" block on
report page 651: `p/p_t` is static over total pressure, `rho/rho_t` static over
total density, `T/T_t` static over total temperature, and `A/A_*` the ratio of
local cross-sectional area to the area of the same isentropic stream tube where
M = 1. Those are exactly the orientations RocketForge uses.

The tables print four significant figures, with a modified exponent notation
described on report page 632: a group of digits followed by a subscript `-n`
means the decimal point moves n places left, so `.2722 -1` is 0.02722. Test
tolerances are set to half a unit in the last printed digit; nothing is
asserted more tightly than the source states.

## NASA Glenn Research Center (independent confirmation of equation form)

* **Title**: *Isentropic Flow Equations*, Beginner's Guide to Aeronautics
* **Organization**: NASA Glenn Research Center
* **URL**: <https://www.grc.nasa.gov/www/k-12/airplane/isentrop.html>
* **Accessed**: 2026-08-30

Used to confirm the *form* of the relations independently of NACA 1135,
including the exponents. The page gives, as its equations 6, 7, 8 and 9:

    T/Tt = [1 + M^2 (gam-1)/2]^-1
    p/pt = [1 + M^2 (gam-1)/2]^-[gam/(gam-1)]
    r/rt = [1 + M^2 (gam-1)/2]^-[1/(gam-1)]
    A/A* = {[1 + M^2 (gam-1)/2]^[(gam+1)/(gam-1)/2]} {[(gam+1)/2]^-[(gam+1)/(gam-1)/2]} / M

which is algebraically identical to the forms implemented in
`rocketforge/physics/compressible/isentropic.py`.

## NASA/TM-2006-214086 (primary source for Fanno and Rayleigh values)

* **Title**: *User Guide for Compressible Flow Toolbox Version 2.1 for Use With
  MATLAB Version 7*
* **Author**: Kevin J. Melcher
* **Report**: NASA/TM—2006-214086
* **Organization**: NASA Glenn Research Center, Cleveland, Ohio
* **Date**: January 2006
* **Copy used**: the scan hosted by the NASA Technical Reports Server at
  <https://ntrs.nasa.gov/api/citations/20060008908/downloads/20060008908.pdf>
* **Accessed**: 2026-08-31
* **Status**: US Government work, public domain.

**Why a second authority was needed.** NACA Report 1135 covers isentropic flow,
normal shocks, oblique shocks and the Prandtl-Meyer function; it contains no
Fanno or Rayleigh tables. Rather than present a Fanno table as though 1135
carried one, Phase 4E went and found an authority that does. This memorandum
tabulates both families and is in the public domain.

Values were read from the printed tables and worked examples in that scan:

| Table / example | Report page | Content used |
| --- | --- | --- |
| Table 4.3 — Fanno-line Flow Properties, Gamma=1.400000 | 38 | M = 0.50 to 0.70 rows |
| Example 4.11 — `fanno(1,3.5,1:7)` | 28 | the supersonic M = 3.5 case |
| Table 4.7 — Rayleigh-line Flow Properties, Gamma=1.400000 | 64 | M = 0.55 to 0.59 and M = 2.0 to 2.4 rows |
| Example 4.24 — `rayleigh(1,[0.72 2.85],2:6)` | 54 | M = 0.72 and M = 2.85 |
| Example 4.25 — `rayleigh(2,TTratio,[1 5])` | 55 | the branch-aware T0/T0* inverse, both roots |

Column headings, from Table 4.2 (report p.28) and Table 4.6 (report p.54):
`T/T*`, `P/P*`, `P0/P0*` and `V/V*` are the state at M over the state at sonic
conditions on the same line, `TT/TT*` and `PT/PT*` are the total-temperature and
total-pressure forms, and `4fL*/D` is the friction parameter. Those are exactly
the orientations RocketForge uses.

**The friction convention is confirmed, not merely assumed.** The report writes
the column as `4fL*/D`, the Fanning group. A Darcy reading of the same duct
would make every value in that column four times smaller, so agreement at
M = 0.5 — published 1.06906, RocketForge 1.0690603127 — confirms the convention
as well as the algebra. That is the check `docs/engineering/03` section 8.2 asks
for.

Tolerances are half a unit in the last printed significant figure of each value,
taken per value rather than per table, because Table 4.3 prints six significant
figures and the worked examples print four or five.

Example 4.25 is transcribed as `inverse_cases`: it gives both the subsonic and
the supersonic root of the same `T0/T0*`, which is the published confirmation of
the one Rayleigh inverse Phase 3 puts in v1.

## Fourth check: the shock as the Fanno–Rayleigh intersection

A normal shock joins two states of equal mass flux and equal momentum flux, in a
constant-area passage, adiabatically. Those are precisely the defining
conditions of the Fanno line (constant area, adiabatic) and of the Rayleigh line
(constant area, frictionless momentum balance), so **the two states either side
of a normal shock lie on the same Fanno line and on the same Rayleigh line**.

That gives an independent check on eight of the nine Phase 4E starred ratios
which needs no Fanno or Rayleigh table at all, and which is anchored to NACA
1135 through the already-accepted normal-shock module:

    fanno.X(M2)/fanno.X(M1)      == normal_shock.X(M1)      for X in p, T, rho, p0
    rayleigh.X(M2)/rayleigh.X(M1) == normal_shock.X(M1)      for the same four

and, because stagnation temperature is conserved across the shock while both
states share one Rayleigh sonic reference,

    rayleigh.stagnation_temperature_ratio(M1) == that of M2

`tests/physics/compressible/test_phase_4e_reuse.py` asserts all nine at 1e-12
over M1 = 1.2 to 8. The observed worst deviation is 6e-16, which is arithmetic
noise rather than physics.

## Speed of sound

`PerfectGas.air()` uses R = 287.0528 J/(kg·K), which is 8314.32/28.9644 from
the *US Standard Atmosphere, 1976* (NASA-TM-X-74335), where 8314.32 J/(kmol·K)
is the gas constant used by that standard and 28.9644 kg/kmol the molar mass of
dry air. The resulting speed of sound at the standard sea-level temperature of
288.15 K is 340.294 m/s, which matches the value tabulated by that standard —
an independent check of the constant, the relation and the arithmetic together.

## What is *not* a source

The values printed in `docs/engineering/03_compressible_flow_specification.md`
section 11 were generated by evaluating the specification's own equations. They
are useful for cross-checking, and they agree with the tables above, but they
are not treated as authority anywhere in this suite.
