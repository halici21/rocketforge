# DB-0 — Conflict ledger

Every material disagreement DB-0 found between sources, kept as separate
claims. Nothing is averaged and nothing is silently resolved. The
machine-readable ledger is [data/conflicts.json](data/conflicts.json) (and
[data/conflict_ledger.csv](data/conflict_ledger.csv)).

A conflict is `resolved: true` only when a source-backed explanation exists
(for example: different operating point, different rating epoch, different
variant, unit conversion, a printed typo, a different definition of the
quantity). Even then both claims stay in the data. Where a claim's origin is
not a registered source (an analyst prior, a page whose URL was not captured),
the claim carries `origin` instead of `source_id` and must not be used as
evidence.
