# DB-0 — Source registry

Every source DB-0 cited, with tier, rights class and access state. The full
registry is [data/sources.json](data/sources.json) /
[data/source_registry.csv](data/source_registry.csv); this page lists Tier A–C
sources and summarizes the rest.

**Access.** No source in this registry was opened. `search_result_only` means
the source appeared in a web-search result and its summary was read;
`not_retrieved` means it is known (cited elsewhere) but was not even seen in a
result; `dead_link` here means the host was refused by the session's egress
policy, **not** that the site is down. Source metadata is retained even when
the document could not be reached, so DB-1 can fetch it.

**Tiers.** A = government/agency/manufacturer primary documents and patents;
B = peer-reviewed, conference, theses, contractor reports; C = textbooks;
D = encyclopedic (Wikipedia, Astronautix, Gunter, Brügge, museum pages);
E = forums, blogs, unsourced aggregation. Tier is assigned per document, so a
Wikipedia page that quotes an NTRS report is still Tier D.

**Rights** are provisional classes (RIGHTS_MATRIX.md); no repository copyright
field or terms page was read.

**Known identifier caveats.**
- NTRS ids recorded here were seen in search results. Where a branch could not
  see the title, the title says so ("title not seen").
- Two document identities were corrected during DB-0: Rocketdyne R-3896-1 is
  the F-1 "Engine Data" volume, not a training manual; and the Apollo LM descent
  propulsion experience report is TN D-7143, not TN D-6837.
- "SSME Orientation" exists as a 1984 Rocketdyne/Rockwell manual (Part A,
  Engine) and as a June 1998 abbreviated-course handout (BC98-04) marked
  "Rocketdyne and Boeing Proprietary"; they are different documents with
  different rights.
- One id collision was split during merge: `SRC-WIKI-VIKING` had been used for
  three different Wikipedia articles (the French engine, the US sounding
  rocket, the Mars program).
- An AI-generated encyclopedia ("LLMpedia") appeared in results; it is listed
  for transparency and none of its values are used.
