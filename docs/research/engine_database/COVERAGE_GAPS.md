# DB-0 — Coverage gaps

This page separates **"not researched"** from **"researched, not publicly
reported"**, as the brief requires. A gap marked *access* means the source is
known and was not opened (§3 of the overview); *not swept* means no search was
spent on it; *not public* means the searches that were run found nothing and
the information is plausibly proprietary or classified.

## 0. The overarching gap: document access

Every gap below sits on top of one that affects the whole package: **no
source document was opened**. All values come from web-search summaries. The
first DB-1 task is a document-access pass (overview §8).

## 2. Engines with poor source coverage despite importance

- **Soviet missile engines** (R-12, R-14, R-16, R-36, UR-100 families): mostly
  placeholders or Tier D.
- **RD-0146, RD-0162, RD-120, RD-301, RD-701/704, RD-0750**: placeholders, even
  though RD-0146 is the parent of MR10 and RD-120 the reported ancestor of
  YF-100.
- **RS-18, SSME Phase II / Block I / Block IIA, RL10C-x, RL10A-3-1/-3-3**:
  placeholders; the block structure of the SSME is recorded only partly.
- **Isayev / KB KhimMash engines** in general.
- **Chinese state engines** below the YF-100/YF-77 tier.

## 4. Missing subsystem data (across the corpus)

Fields that are missing for almost every engine, including anchors:
injector element counts and Δp; cooling channel count, dimensions and coolant
states; pump inlet/discharge pressures per pump (exceptions: RS-25 sheet, Vulcain
2 LOX TP); shaft speeds (exceptions: F-1, H-1, LE-7/7A, LE-9 one pump, A4,
SSME secondary); turbine inlet temperature and pressure ratio; GG/preburner
mixture ratio and temperature (exceptions: RD-0120 preburner, LE-7A preburner
gas temperature, 11D58MF GG pressure); start and shutdown sequences; valve
inventories; engine mass definitions (dry vs wet, with or without gimbal).

## 6. Unresolved aliases and variants

- NK-33 = 11D111 or 14D15 (and NK-33A); NK-43 → AJ26-59 or AJ26-60.
- RD-170 = 11D521 and RD-171 = 11D520, seen only through a reference title.
- 11D43 for RD-253, 8D412K for RD-0211, 8D75 for RD-108 — not confirmed.
- RD-57 = 11D57 only inferred.
- Naro-1 first stage: RD-151 (SpaceNews, Spaceflight Now) vs RD-191 (Wikipedia
  infobox).
- Agena 8096 = XLR81-BA-11 or BA-9; Atlas MA-5 booster LR89-5 or LR89-7.
- LM ascent engine alias "Bell 8258" / "RS-18"; LMDE alias "TR-200"; Gemini
  "SE-7".
- MB-60 alias collides with RL60.
- "Merlin Vacuum" / "MVac" span Merlin 1C Vac and 1D Vac.
- RS-25D vs "SSME Block II" merged on the anchor's scope statement; Block IIA
  kept separate. DB-1 should model these as configurations of one RS-25
  variant line.
- Thunder-R2 excluded (no source for its existence).
- Id prefix convention for Soviet/Russian engines (`ENG-SU-` vs `ENG-RU-`).
