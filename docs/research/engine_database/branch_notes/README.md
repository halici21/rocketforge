# DB-0 branch notes (raw)

The narrative notes each DB-0 research branch wrote, kept unedited for
provenance. They are **working notes, not findings of record**: the merged and
reviewed results are the documents one level up and the data in `../data/`.

- Round 1: `us_hist`, `commercial`, `ussr`, `europe`, `asia_other`,
  `spacecraft`, `taxonomy`, `rights`, `anchor_us_classic`, `anchor_us_modern`,
  `anchor_ussr`, `anchor_eu_asia`.
- Round 2 (gap filling, budgeted searches): `r2_us_classic`, `r2_ussr`,
  `r2_asia`, `r2_sc_comm`, `r2_schem`.

Tags used inside them: `[S: …]` seen in a search-result summary; `[BG]` / `[BK]`
analyst background knowledge, **not verified** and never used as a value;
`[INF]` classification reasoning. Each note lists the documents to open first
when network access allows — that is their main value to DB-1.

Several round-1 notes describe the branch as blocked: the egress policy refused
document hosts and the shared search budget ran out. Round 2 superseded those
gaps where it could; the merged data always prefers round-2 records.
