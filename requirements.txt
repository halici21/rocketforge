# Engineering backend. NumPy is the one numerical dependency: the compressible
# relations are vectorised so the Analysis pages can sweep thousands of Mach
# numbers per frame without a Python-level loop (ADR-09/ADR-10 in
# docs/engineering/01_engineering_architecture.md). Added in Phase 4B, the first
# phase whose production code actually imports it.
#
# SciPy is deliberately NOT here: the bracketed root solver is RocketForge's own
# and tests/test_architecture.py fails the build if any backend module imports
# SciPy. Pandas is not a dependency either.
#
# The floor is the oldest NumPy with CPython 3.13 wheels (2.0.x has none), so it
# is the oldest version this project can install at all. The minimum-versions
# CI job installs exactly this floor and runs the suite on it.
numpy>=2.1
